# Quantum's Stupid Little Editor

This is very experimental. So I wouldn't expect much yet.

### Who is it for

This project is for people who like the shortcuts found in modern day applications such as VS Code and want a powerful terminal editor. This terminal editor is heavily inspired by nano, but I want more modern autocomplete features, syntax hightlighting, and inline documentation without the cost of a full language server protocol.

### Controls

Closing the program: Press the ESC key to close the program

### Disclosers

*This editor contains a lot of platform specific code, will not compile correctly on non-Unix systems, and is only tested on Debian 13 Linux*
